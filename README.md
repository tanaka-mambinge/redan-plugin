# Redan Plugins

Codex marketplace for Redan Zimbabwe management tools.

## Add the marketplace

In Codex, choose **Add plugin marketplace** and enter:

```text
https://github.com/tanaka-mambinge/redan-plugin
```

Then install **Redan Management** from the `redan-plugins` marketplace.

The plugin lives under [`plugins/redan/`](plugins/redan/), matching the marketplace layout used by the Takealot reference project.
